# 07 Interaction and States｜交互与状态

[Figma 状态样例](https://www.figma.com/design/7dVg1Mgu2O9Gnsg1mwrGRf?node-id=175-4384)

| 状态 | 界面反馈 | 保留和恢复 |
| --- | --- | --- |
| 生成中 | 保留产物标题或任务描述；区域内提示「正在生成商品清单…」。 | 保留对话和原始请求；避免启动相同任务多次。 |
| 加载 | 已有表格占位时保留表头及区域高度；加载反馈放表身。 | 保留筛选、页码位置；不把加载显示成零。 |
| 完成 | 展示结果摘要和可操作内容。 | 保留范围；切换分屏不丢状态。 |
| 编辑 | 按原稿动作进入当前产物编辑；可识别正在编辑的对象。 | 未保存的内容留在编辑区；退出时明确有无更改。 |
| 局部更新 | 在请求对应的列、行或明细区给出反馈。 | 不擦除未更新的数据；失败保留旧值，明确未更新部分。 |
| 失败 | 区分生成失败、列表读取失败和局部失败；提供适当的重试动作。 | 保留输入、筛选、表头和已有结果。失败时不把上次结果数当作当前结果；首次加载失败或条件已变时隐藏计数。重试沿用同一条件。 |
| 空状态 | 区分暂无产物、数据为空、筛选无匹配、无权限。 | 无匹配可清除筛选；无权限只有存在授权路径才给入口。 |

- [原稿暂无产物](https://www.figma.com/design/7dVg1Mgu2O9Gnsg1mwrGRf?node-id=119-19989)、[原稿二次操作](https://www.figma.com/design/7dVg1Mgu2O9Gnsg1mwrGRf?node-id=119-11550)优先；图中生成、局部更新文案和反馈是设计补充。
- 查询时保留输入；错误就近提示。反馈消息允许换行，行高为字号的 1.5 倍。
- 状态对照复用三个 352 px 表格实例，各间隔 12 px。展示板给三列留足宽度，实例圆角、描边和列宽保持原尺寸。
- 此文档说明界面行为及状态转换。真实请求、滚动固定、分页和任务执行由联调验证。
