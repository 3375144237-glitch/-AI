## 输入及优先级

- 识别业务对象、用户任务、可用字段、产物宽度、当前状态和授权范围。
- 优先级：已确认设计规则 → 同页原稿实测 → 已有组件 → 必要的补充状态。没有依据的组件和字段不生成。
- 先输出设计布局及组件用法，再出稿。记录用到的已有组件名、场景和对应的原稿入口。

## 选择条件

| 用户任务 | 布局与组件 |
| --- | --- |
| 快速看异常 | 固定分屏；摘要后接结果。优先异常数量和明细入口。 |
| 查商品或筛选 | 关键词用 Input，渠道与状态用 Select，结果用 Table。 |
| 对比多列 | 展开或全屏；表头与数据列对齐，保留同一数据范围。 |
| 翻页 | 超一页才显示 Pagination；窄栏用简版；已知总量且有需求才展示总数或跳页。 |
| 反馈异常 | 有旧数据保留旧内容；无数据、无匹配、无权限、失败按语义复用 Empty State。 |

## 可直接使用的设计提示词

> 为售卖 AI 的运营人员设计右侧库存异常产物。用户需要在对话旁查找异常商品并进入明细。先显示统计范围和异常数，再显示关键词、渠道、状态与商品清单。有效宽度 374 px，复用 Input、Select、Table、Tag；保持控件高 32、组距 8、列表上间距 12。仅使用已提供的数据，空值显示「—」。没有多页结果就不生成分页。使用苹方；单行行高等于字号，可换行时用 1.5 倍。完成后输出主要验证点以及任何没有原稿依据的补充。

## 禁止与验收

- 禁止自行推断数据与权限、堆叠重复指标、把错误当无数据、整行使用绿色、缩字号挤宽度。
- 灰底普通文字用 `#333333`，浅绿底配主绿描边时文字用主绿。Select 灰底选项不加对号。
- 不新增时间选择器、穿梭框、营销组件，或重复实现现有组件。Element UI 只用来补充必要的场景。
- 验收适用宽度、可见信息优先级、原稿对齐、字号行高、全状态、组件复用和错误恢复。
