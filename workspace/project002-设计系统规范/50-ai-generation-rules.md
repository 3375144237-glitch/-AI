# 售卖 AI｜聊天产物 UI 生成与验收规范

v1.1 · 适用于右侧的**分屏网页、报告和表格预览**。先读本文，再按需查 [设计交付索引](00-design-delivery.md)。固定分屏、展开和全屏共用本规范。

## 1. 执行方式与依据

| 标记 | AI 怎样执行 | 设计师怎样判断 |
| --- | --- | --- |
| 必须 | 检查对应条件；不满足就修正，无法核对就标为待核 | 按规则编号和参考稿核对 |
| 禁止 | 不生成该元素、动作或数据；已生成则移除 | 出现即退回 |
| 默认 | 用户未指定且定稿无更贴近的同场景用法时采用 | 改用其他方案须说明依据 |
| 设计补充 | 定稿未覆盖时，以现有组件、变量组合最小方案；在交付记录里标明 | 核对参照场景；新增组件、样式或关键交互须设计确认 |

- **SRC-01｜按来源分工。** 用户定义任务；数据和权限决定内容与动作；同场景 Figma 定稿决定视觉与布局。先读对应评论，再查组件、变量和仓库规则。旧 Demo 用于核对业务。冲突项记为待核，其余按已确认规则推进。
- **SRC-02｜定稿只读。** 未获用户明确授权，不得写入指定范围以外的 Figma 图层，或经组件、样式、变量及交互间接改动定稿。生成产物复用现有组件与样式。
- **SRC-03｜区分宿主和产物。** 会话、侧栏、产物标签、地址栏和预览控件由宿主承载。产物仅生成业务内容与控件；不复制宿主导航、不改写宿主主题、不模拟宿主能力。样式限于内容区。
- **SRC-04｜禁止把示例当能力。** 下文报告和表格规则约束的是产品内的阅读与预览界面。可内嵌格式、源文件下载、跨会话恢复等以产品实际提供的能力为准；无预览能力时区分格式不支持、文件失效和无权限，只提供真实可用的入口。

## 2. 把聊天请求变成产物

1. **GEN-01｜提取输入。** 从会话和产品上下文提取任务、对象、范围、数据来源、可用权限、内容宽度和状态。图表、筛选和编辑按任务需要选择。
2. **GEN-02｜选择模板。** 优先用用户指定的类型；未指定时按下表选主模板，混合内容做子区块。简单问答在聊天中答；需要阅读、对比或操作时生成分屏产物。
3. **GEN-03｜处理缺项。** 会改变结论的对象、范围或口径缺失时追问；非关键缺项可注明。无数据时用空预览或空结构，不填看似真实的样例；按要求制作演示数据时注明「示例数据」。
4. **GEN-04｜按顺序交付。** 选画板和组件 → 生成 → 核对实际宽度与状态 → 记录结果。
5. **GEN-05｜按受众筛选文案。** 原型、截图和 HTML 里的研发实现说明、演示接入提示、交互占位及设计备注留在交付记录。界面保留用户需要的对象、状态、范围、风险和动作；仅用样例或模拟核验时，在相关数据旁标明。要求沿用原文时只删重复或内部内容，不补造文案和事实。
6. **GEN-06｜同一模块按口径去重。** 对象、范围、口径和用途均相同时，选读者查找该信息的位置保留一次：范围放摘要，逐条状态放结果行，适用于整表的提示放表旁。保留有独立用途的跨视图汇总、逐条明细和必要警示；不合并不同对象或口径。

| 用户要完成的事 | 模板 ID | 区块顺序 |
| --- | --- | --- |
| 看经营异常、查找后处理或跟进 | `split_web` 分屏网页 | 标题与可用主操作 → 范围和关键指标 → 可选视图、筛选 → 结果 → 明细或下一步 |
| 了解发生了什么、为什么、有什么建议；阅读交付包 | `report` 报告 | 标题与范围 → 关键结论 → 依据和明细 → 建议或附件目录（按需） |
| 查看、筛选或对比一批同结构记录 | `table_preview` 表格预览 | 表名与范围 → 可选筛选和结果数 → 表头与表身 → 可选分页或明细 |

## 3. 共用视觉约束

复用 [Tokens](10-tokens.md) 和 [Components](20-components.md)；同场景定稿优先。

| 规则 | 必须执行 |
| --- | --- |
| VIS-01 表面与文字 | 页面 `#F7F8FA`，内容白底，表头、整行悬停或选中、灰底控件用 `#F5F7FA`。灰底普通文字用 `#333333`；辅助、次要文案（如时间、范围说明、备注）优先 `#999999`，需更高对比度时按场景规范取色。表头、关键数据、操作与状态各按语义取色。外框 `#E5E5E5`，表内行线 `#EBECF0`，通常 1 px。 |
| VIS-02 用色语义 | 主操作和聚焦沿用主绿 `#2ABD90`；警示及字段错误用 `#FF6C3A`，必填星号保留独立语义。局部浅绿底配主绿描边时用主绿字；整行不涂绿。Tag 直接复用语义变体，包括底色透明度。 |
| VIS-03 字体 | 苹方 `PingFang SC`，字距 0。未指定标题样式时，分屏区块标题用 16 Medium，正文用 14 Regular，密集表格用 12。新生成区域：单行行高 = 字号，允许换行行高 = 字号 × 1.5。原稿例外随组件保留；环境缺字体时记录实际回退并复核换行，Figma 原稿不静默换字体。 |
| VIS-04 间距与圆角 | 复用 4/8/12/16/20/24/32/40 px 间距集合。常用图文或同组控件距 8、单元格内距 12、分屏内容留边 16。常见圆角：Tag 4、筛选 6、表单 8、表格 12、弹窗 16。普通面板与表格不加阴影，浮层用已有阴影。 |
| VIS-05 层级与可操作性 | 同一任务区最多一个主操作。靠标题、留白和对齐分组；多表格报告的模块之间不加横线，保留表格自身边线。禁止营销横幅、装饰渐变、大面积强调色和卡片嵌套。键盘焦点可见且顺序与视觉一致，图标按钮有可访问名称；警示、选中和错误有文字或可识别标记。 |
| VIS-06 相邻文案 | 同组两条文案上下相邻且行高均等于字号时，优先以 6 px 为间距（如 4 调到 6），必要时用 8 px；组内仍小于组间。任一条为 1.5 倍行高时沿用该场景间距。不改行高，定稿与现有组件规格优先。 |
| VIS-07 标题同行 | 先按对象和作用分组。用实际字号测标题自然宽度 `T`，以扣除内边距的行宽 `W` 为准。仅当 `T ≤ W / 2` 且标题、间距、同组附属内容能完整同排时，右侧可放该内容；其余放在标题下方。宽度或文案变化时重算，不压缩字号或截断来强行同排。 |

| 业务需要 | 优先复用 | 判定要点 |
| --- | --- | --- |
| 提交、关闭、明细 | Button | 使用原稿变体：主色用于主要动作，灰底用于关闭，文字用于明细。常用中号高 32；查询及关闭样例 64×32，圆角分别 8、6。仅在业务允许时展示写操作。 |
| 关键词或字段输入 | Input | 商品搜索高 32、圆角 6；普通字段高 32、圆角 8。搜索默认无填充，沿用原稿图标。 |
| 有限选项 | Select | 筛选款高 32、圆角 6。灰底选项用 `#333333`，不加对号。 |
| 状态与计数 | Tag / Badge | 状态用文字标签，数值用真实数据。Badge 的缩写规则不能替代表内真实数值。 |
| 多条记录和翻页 | Table / Pagination | 数据超一页或确定有下一页时才分页；窄栏优先简版。无总数时不猜总量或提供跳末页。 |
| 缺结果或失败 | Empty State | 按有无数据、无匹配、无权限、失败复用对应状态；不能拿空状态掩盖错误。 |

## 4. 三类产物的布局规则

**LAY-01｜按有效宽度排版。** [Figma 的 374 / 574 / 1034 px 样例](https://www.figma.com/design/7dVg1Mgu2O9Gnsg1mwrGRf?node-id=174-3852)用于验收，不是浏览器断点。按扣除宿主和外边距的剩余宽度排版；固定列表后重排，保留范围、结果、关键词、筛选和选中项。

| 规则 | 374 px 固定分屏 | 574 px 展开 | 1034 px 全屏 |
| --- | --- | --- | --- |
| WEB-01 分屏网页 | 首屏保留对象、范围、关键风险和下一步。指标按内容折行；次要字段进明细。 | 可同时展示摘要、筛选和更多状态列。 | 适合跨渠道和跨列比较；增加可比较的信息，不放大字号。 |
| REP-01 报告 | 标题、范围、结论置顶；正文单列可换行，附件逐行。关键结论无需横滚。 | 保留阅读顺序，有空间时按原稿用并排附件或数据资产。 | 保持正文易扫描；横向空间留给数据对比和资料分组。 |
| TAB-01 表格预览 | ID 或名称、关键状态和必要操作可定位；多列在表格内部横滚，或由宿主展开。 | 显示更多对比列，原列仍可定位。 | 展开任务所需且有权限的列；保持同一范围和字段口径。 |

- **WEB-02｜商品看板特例。** 商品视图高 36；视图到筛选 16，搜索和两个 Select 高 32、组距 8、三列等宽，结果数随文字；筛选到表格 12。374 px 参考样例的页签组距 16，574/1034 px 为 32。放不下时允许横向浏览、把次要工具收起或重排；不要缩字号。全量对账、重试同步等业务按钮只有宿主提供对应能力且用户有权限时才展示。
- **REP-02｜报告内容。** 标题写对象，范围写有依据的时间和渠道。用一组简短结论带出证据；数字旁标单位、口径、适用范围或来源。建议用短句写行动与前提，不把相关性写成因果。仅当有真实文件时按原稿展示附件名、类型及可用的打开动作。文档包可用编号阅读顺序；普通报告不强制加目录。仅当数据和任务都支持时展示图表；缺少既有图表样式时使用表格或标记为设计补充，禁止在图里补造区间或趋势。
- **TAB-02｜表格结构。** 沿用浅灰表头、12 px 外框圆角、1 px 描边；商品表头 40 px，双行商品数据行以 56 px 为样例。表头和单元格对齐；可比较数值沿用同场景的对齐方式，无同类稿时右对齐并保持单位一致。SKU、编码当文本，保留前导零。长商品名可省略，完整值能在明细或可访问提示中查看；表格横滚不带动整页。
- **TAB-03｜预览能力。** 默认只读。只在真实支持时提供排序、搜索、筛选、冻结列、分页、工作表切换、编辑和下载；当前工作表和筛选范围要可辨认。表格预览与原文件列名、值、单位一致。预览仅加载部分数据时标明范围，不能把当前页计数当全表总量。

## 5. 数据与状态

- **DATA-01｜忠于数据。** 不猜测指标、时间、筛选结果、合计、权限或后台执行结果；真实零值显示 `0`，缺失或不适用显示「—」，需要区分时在附近说明。商品库存异常归库存；同步状态与失败数归同步；同一记录可同时呈现两类异常。报告的结论、表格和看板必须用同一口径或清楚说明范围差异。
- **DATA-02｜限制范围。** 只展示当前会话的授权产物和业务字段。无权限不显示受限行、摘要、计数或预览图；仅在存在授权路径时展示申请入口。业务写入不会因打开、切换视图或刷新产物而自动触发。

| 规则 | 条件 | 产物里的反馈 |
| --- | --- | --- |
| ST-01 | 生成中或首载 | 保留任务标题；用就近反馈说明正在生成或加载。已有表格结构则保留表头；不把加载当作 0。 |
| ST-02 | 可用或部分可用 | 展示已确认结果；未提供的字段或仍在更新的范围单独说明，勿把部分结果当完整。 |
| ST-03 | 真实为空或筛选无匹配 | 分别写「暂无数据」和「未找到匹配结果」。仍有筛选时提供实际可用的清除入口，保留结构和条件。 |
| ST-04 | 读取、生成或局部动作失败 | 说明哪一部分失败；保留同一条件下已有的授权内容，并标为上次结果；条件改变或首载失败时隐藏旧计数。能重试时在原位置提供重试，沿用同一条件。 |
| ST-05 | 无权限、失效、格式不支持 | 三者用不同原因和动作；已有数据不跨权限或跨会话复用。 |
| ST-06 | 支持编辑或二次操作 | 通过现有详情、抽屉或编辑控件操作；保留列表与筛选。提交中防重复，失败保留可恢复输入，高风险写操作按现有产品规则确认。 |

## 6. 生成示例与验收

下面的 YAML 是团队可读的生成计划示例，可作为模型输出的决策记录。它不规定前端接口。

```yaml
template: split_web
request: "在聊天旁看华东店铺的库存预警，并打开商品明细"
scope: "华东店铺；沿用本次查询范围"
content_width_px: 374
reference: "Figma 203:28454 / 固定分屏"
sections: ["范围", "有依据的异常摘要", "筛选", "商品清单", "明细"]
components: ["Input/search", "Select/filter", "Table/fixed", "Tag", "Button/ghost"]
state: ready
omit: ["内部实现说明", "模块内同口径重复项", "未授权动作"]
```

| 聊天输入 | 应生成 | 验收时退回的情况 |
| --- | --- | --- |
| 「把本周各渠道同步情况写成简报。」 | `report`。先写范围和关键结论，再给各渠道证据、未覆盖范围与下一步。仅凭现有数据下结论。 | 把上周当本周；编造渠道数据、趋势或失败原因；窄栏正文横滚。 |
| 「打开 SKU 清单，比较可用库存和同步状态。」 | `table_preview`。保留商品或 SKU、库存和同步状态；窄栏通过表内浏览或展开对比。 | 前导零丢失；把缺失当 0；同步失败盖掉库存异常；显示不能用的排序、编辑或下载。 |

**交付检查：** 记录适用项的「通过 / 待核 / 退回」及证据；无法预览或验证的项标为待核。

| 检查 | 通过条件 |
| --- | --- |
| A1 意图和信息 | 模板匹配聊天目标；能定位对象、范围、关键结论和下一步。 |
| A2 视觉与复用 | 有同场景画板及组件依据；字体、颜色、可见填充、行高、间距和边线可对照。未经确认的新设计有清楚标记。 |
| A3 宽度与键盘 | 核对实际分屏宽度和适用的 374/574/1034 样例；长文案、宽表和焦点不会盖住关键数据或控件。切换宽度不丢条件。 |
| A4 数据与状态 | 核对 0 与缺失、无匹配、首载失败、保留旧数据、无权限；同一指标跨报告、页面和表格口径一致。 |
| A5 能力与定稿 | 动作可用且合规授权；定稿保持只读。 |
| A6 文案 | 内部备注未上屏；同一模块无无意义复述；数据状态和不同口径仍可区分。 |
