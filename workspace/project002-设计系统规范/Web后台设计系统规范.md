# 售卖 AI Web 后台设计系统规范

v1.1 · 适用于商品、库存和运营管理等中高密度后台。

依据 [Figma UI稿](https://www.figma.com/design/7dVg1Mgu2O9Gnsg1mwrGRf?node-id=0-1)的看板、商品表格、首页、输入和权限弹窗。「原稿」为实测；Dark、分页与完整空态为建议。评论未能读取（401）。

## 1. Foundations

### 1.1 设计原则

1. **任务优先。** 先呈现对象、范围、状态和下一步；每个任务区突出一个主操作。
2. **密集可扫读。** 用对齐、字号和细线分组；少用大标题、装饰色块和卡片嵌套。
3. **反馈就近。** 错误贴近字段；失败保留输入与筛选。
4. **支持键盘。** 焦点可见，顺序与视觉一致；状态附文字或图标。交互目标至少 24×24 px，触屏优先 44×44 px。

### 1.2 色彩体系

Light、Dark 主色均为 `#2ABD90`。薄荷底配深色前景（6.73:1）；小字号文字按钮和链接用 `action/text`。

| Token（统一前缀 `color/`） | Light | Dark | 用途 |
| --- | --- | --- | --- |
| `bg/canvas` | `#F7F8FA` | `#11161A` | 页面底 |
| `bg/surface` | `#FFFFFF` | `#191F24` | 内容面、浮层 |
| `bg/subtle` | `#F5F7FA` | `#20282F` | 表头、悬停底 |
| `text/primary` | `#333333` | `#EFF2F4` | 标题、正文、数据 |
| `text/secondary` | `#666666` | `#B4C0C8` | 辅助文字 |
| `text/placeholder` | `#6B7077` | `#A7B3BD` | 输入占位 |
| `border/subtle` | `#E5E5E5` | `#343E47` | 容器细线 |
| `border/control` | `#83898F` | `#707E8A` | 可操作控件边界 |
| `border/focus` | `#205FCC` | `#91B8FF` | 键盘焦点 |
| `action/primary` | `#2ABD90` | `#2ABD90` | 主按钮底、品牌图形 |
| `action/hover` | `#24AE84` | `#24AE84` | 主按钮悬停 |
| `action/pressed` | `#1EA078` | `#1EA078` | 主按钮按下 |
| `action/text` | `#14765A` | `#64D9AF` | 链接、文字按钮 |

| `text/disabled` | `#777D84` | `#9AA7B2` | 禁用文字，不用于只读 |

普通字和占位至少 4.5:1；大字、可操作控件边界、必要图标和焦点至少 3:1。

### 1.3 字体层级

原稿用 `PingFang SC`，首页问候 32/32、600 为特例。字距 0；回退用 `Microsoft YaHei`、`Noto Sans SC`、系统无衬线。数值列优先等宽数字。

| Text Style | 字号 / 行高（px） | 字重 | 用途 |
| --- | --- | --- | --- |
| `Heading/Page` | 24 / 32 | 600 | 页面标题 |
| `Heading/Section` | 20 / 28 | 600 | 区块标题 |
| `Heading/Panel` | 16 / 24 | 500–600 | 面板、弹窗 |
| `Body/Default` | 14 / 20 | 400；强调 500 | 正文、表单 |
| `Body/Dense` | 12 / 16 | 400；表头 500 | 密集表格、短说明 |

### 1.4 间距系统

以 4 px 为底，取 `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`。4 微间距，8 同组控件，12 单元格内边距，16 字段或窄分屏留边，24 页面留边，32–40 大区块。原稿侧栏留边 16、表格左内边距 12、筛选间距 8。

### 1.5 圆角

| Token（前缀 `radius/`） | px | 用途 |
| --- | --- | --- |
| `xs` | 4 | Tag |
| `sm` | 6 | 页码、轻量选中底 |
| `md` | 8 | Button、Input、Select |
| `lg` | 12 | 表格外框 |
| `xl` | 16 | 弹窗 |
| `composer` | 24 | 对话输入容器 |
| `pill` | 999 | Badge |

### 1.6 阴影

普通表格和面板无阴影；浮层建议如下。

| Effect Style | 几何（x y blur spread） | Light / Dark 黑色透明度 | 用途 |
| --- | --- | --- | --- |
| `Elevation/Popover` | `0 4px 12px 0` | 10% / 35% | 下拉、悬浮面板 |
| `Elevation/Modal` | `0 12px 32px 0` | 16% / 50% | 弹窗、前景抽屉 |

### 1.7 边框

容器和控件默认 1 px；表格以横线为主，原稿用 `#EBECF0`，Dark 建议 `#303A43`。焦点外环 2 px，距边缘 2 px，避免裁切；错误描边与焦点可并存。弹窗遮罩原稿为黑色 40%，Dark 建议 60%。

### 1.8 状态色

| 语义 | Light 前景 / 背景 | Dark 前景 / 背景 | 示例 |
| --- | --- | --- | --- |
| `success` | `#17664E` / `#E6F5EE` | `#92E2BF` / `#20382F` | 同步成功 |
| `warning` | `#955014` / `#FFF2E0` | `#F7BD72` / `#3A2D20` | 库存偏低 |
| `danger` | `#B42318` / `#FDECEA` | `#FFAAA3` / `#412628` | 同步失败 |
| `info` | `#245DC0` / `#EAF2FF` | `#A5C9FF` / `#202F46` | 审核中 |
| `neutral` | `#666666` / `#F5F7FA` | `#B4C0C8` / `#20282F` | 未同步、已停用 |

原稿用绿、橙、蓝及 10% 色底。规范将预警和失败分色；「天猫」是渠道名，渠道状态需另给可读文字。

### 1.9 Light / Dark 模式

- **Light：** 白色内容面配浅灰底；相邻白色区用留白或细线。
- **Dark：** 用明度与描边分层；浮层可用 `bg/subtle`。状态独立配色，固定列与下拉也随主题切换。
- **切换：** 保存「跟随系统 / 浅色 / 深色」偏好。共用布局和变体，分别验收焦点、错误、选中行与弹层。

## 2. Components

单位为 px。同组控件等高；列表和分屏用紧凑型，表单用默认型。

### 2.1 Button · 按钮

- **用途：** Primary 执行主操作；Secondary 用于取消、导出等次级动作；Tertiary 用于行内轻操作；Danger 用于高风险动作。
- **尺寸：** 高 32 / 36 / 40，横向内边距 12 / 16 / 16，圆角 8，图标 16，图文间距 8。纯图标等宽高。原稿确认按钮为 96×38、圆角 8。
- **状态：** 默认、悬停、焦点、按下、加载、禁用；加载保持宽度。危险操作用危险色前景及描边，按影响决定是否二次确认。
- **禁用规则：** 处理中防止重复提交；前置条件不足时就近说明。无权限时隐藏动作，或提供独立申请入口。
- **文案规则：** 动词加必要对象，如「保存」「删除商品」；「知道了」只确认已读。给纯图标按钮可访问名称。
- **什么时候不要用：** 跳转用链接，换视图用 Tabs；行内次要操作避免用主按钮。

### 2.2 Input · 输入框

- **用途：** 自由输入或搜索名称、编码等；多行用 Textarea，附件和发送组合为 Composer。
- **尺寸：** 高 32 / 36 / 40，圆角 8，横向内边距 12；字 14/20，密集 12/16。Textarea 默认 3 行，达上限后内滚。原稿搜索高 32，对话输入 700×108、圆角 24。
- **状态：** 默认、悬停、焦点、已填写、错误、只读、禁用。搜索可清除；错误保留原值；输入法组字期间 Enter 不提交。
- **禁用规则：** 上游条件未满足时可禁用并说明；需要阅读或复制内容时用只读。
- **文案规则：** 常驻标签配占位「搜索 SPU 编码 / 商品名称」；错误写修正方法，如「请输入 8 位 SKU 编码」。
- **什么时候不要用：** 枚举用 Select；日期、布尔值等用专用控件。

### 2.3 Select · 选择器

- **用途：** 从固定集合单选或多选；选项多或为远程数据时提供搜索。
- **尺寸：** 高 32 / 36 / 40，圆角 8，横向留边 12，图标 16；菜单项高 32 / 36，约 6–8 项后滚动。原稿分屏为 32 高、圆角 8。
- **状态：** 默认、悬停、焦点、展开、已选、错误、加载、无匹配、禁用。区分高亮与已选；方向键移动、Enter 选中、Esc 关闭并回焦点。
- **禁用规则：** 上游未选时禁用；单项不可选时说明原因。接口失败提供重试。
- **文案规则：** 表单用「请选择渠道」，无列表过滤用「全部渠道」；多选溢出显示「+N」。
- **什么时候不要用：** 少量且须同时可见的选项用单选组，自由值用 Input，视图切换用 Tabs。

### 2.4 Tag / Badge · 标签与角标

- **用途：** Tag 表示类别或状态；Badge 报告计数或未读。可撤销的筛选 Tag 可带移除操作。
- **尺寸：** Tag 高 20 / 24、字 12/16、横向留边 6 / 8、圆角 4（原稿高 20）。Badge 高 16 / 20，最小宽等高；圆点 6–8。移除热区 ≥24×24。
- **状态：** Tag 用五种语义色，静态无悬停和焦点；移除键有独立反馈。Badge 区分圆点、数字、溢出。
- **禁用规则：** 静态标签无禁用态；不可移除时省略关闭键。「已停用」是业务状态，文案保持清楚可读。
- **文案规则：** 用「审核中」「同步失败 · 3」等明确词。同状态同词；Badge 默认隐藏零，超过 99 显示「99+」。
- **什么时候不要用：** 不用角标代替筛选、正文或操作；不同业务状态不要揉进一个标签。

### 2.5 Pagination · 分页

- **用途：** 列表或表格批次浏览。已知总量用页码，未知用前后翻页。原稿有「共 4 条」，未见标准分页。
- **尺寸：** 页码与箭头 32×32、间距 4、圆角 6，页容量同高。窄区仅保留上一页、位置、下一页。
- **状态：** 默认、悬停、焦点、当前页、加载、禁用。当前页用 `aria-current="page"`；变更后宣布结果；更改筛选或页容量回到第 1 页。
- **禁用规则：** 首末页禁用对应箭头，加载防重复；一页或空表省略分页。删空当前页后回退到有效页。
- **文案规则：** 「共 128 条」「20 条/页」「第 2 页」；箭头有名称，未知总量不猜总页数。
- **什么时候不要用：** 一屏可比较的结果只报总数；实时日志优先按时段查询或加载更多。

### 2.6 Empty State · 空态

- **用途：** 解释内容为何为空，并给可执行的下一步；保留页面标题和相关筛选。
- **尺寸：** 表内最小高 160，上下留边 24，标题 14/20、说明 12/16、图标可选 24。页面级最小高 240，标题 16/24、图标 32–40。
- **状态：** 首次无数据→创建或导入；无匹配→清除筛选；失败→重试；无权限→申请或返回。加载用骨架或进度。
- **禁用规则：** 容器无禁用态，不显示无权限的灰按钮；存在授权流程才给入口。重试中防重复触发。
- **文案规则：** 点名对象和下一步，如「没有符合条件的商品」＋「调整或清除筛选后再试」，按钮写「清除筛选」。
- **什么时候不要用：** 单字段缺失用「—」；刷新失败但已有数据时保留旧数据，并就近标明未能更新。

### 2.7 Table · 表格基础规则

- **用途：** 扫描、比较和批量处理结构化数据。标题与工具在上，分页在下；表头与表身共用列宽。
- **尺寸：** 原稿表头 40、双行 56、单元格左内边距 12、外框圆角 12。建议单行 40 / 48，双行从 56 起，内容过长可增高。文本左对齐，数量、金额和比率右对齐，操作列放末尾。
- **状态：** 行默认、悬停、已选、焦点；表头标排序方向；整体覆盖加载、无数据、无匹配、错误。批量操作才加勾选；固定列提示横滚。
- **禁用规则：** 按动作或勾选项禁用并说明，不整行泛灰。跨页选择明确作用范围；改筛选时清除勾选或提示保留范围。
- **文案规则：** 列名明确口径，如「可用库存」「同步成功率」；`0` 区别于缺失「—」。库存风险留在库存列；同步列保留同步结果或失败数。行操作使用「查看明细」「重试同步」。
- **什么时候不要用：** 单对象用描述列表，概览用指标，简单集合用普通列表。

优先用原生 HTML 表格，排序列头标记 `aria-sort`。截断值须支持键盘查看或进入详情。需要单元格编辑和导航时才用交互式 Grid。

## 3. Figma 与页面组织

### 3.1 Figma Variables 命名建议

| Collection | Mode | 变量示例 |
| --- | --- | --- |
| `Primitives` | `Default` | `palette/mint/500`、`space/12`、`radius/md` |
| `Semantic` | `Light`、`Dark` | `color/bg/surface`、`color/status/success/fg`、`color/status/success/bg` |
| `Component`（按需） | `Default` | `button/primary/bg/default`、`input/border/error` |

变量用小写与斜杠；按 `Component → Semantic → Primitives` 引用，只切语义模式。间距、圆角用 Number；字体、阴影用 Text Styles、Effect Styles。

### 3.2 Figma 组件命名建议

组件集沿用第 2 节英文名（Tag 与 Badge 分开），表格行用 `Table/Row`。示例：`Variant=Primary, Size=MD, State=Default`。文案用 Text，显隐用 Boolean，图标用 Instance swap。不设 `Property 1` 或主题变体。对话输入归 `Pattern/Composer`。

### 3.3 页面结构建议

- **Figma：** `01 Foundations`、`02 Components`、`03 Patterns`、`04 Screens`、`99 Archive`。画板名如 `商品 / 看板 / 筛选无结果`。
- **后台列表：** 导航 → 标题与主操作 → 可选指标与视图 → 搜索筛选 → 内容 → 分页。原稿标题栏高 52；列表标题左对齐。
- **分屏：** 原稿 1366 宽，侧栏 300、对话区 460、右侧为预览。窄区允许筛选换行与表格横滚；需要时提供全屏，不缩字号。
